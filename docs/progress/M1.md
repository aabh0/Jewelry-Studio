# M1 — Providers and capability registry

- Cloud API client (`src/providers/higgsfield/cloud`): `Authorization: Key id:secret`, submit with `Idempotency-Key` and no POST retries, status polling with backoff, cancel, estimate, presigned upload (echoing `upload_headers`), download. Endpoint catalog with formula estimates.
- CLI adapter (`src/providers/higgsfield/cli`): finds the binary on PATH and in Mac/Windows global dirs, `generate create … --wait --json`, session-expiry detection → `needs_login`, credit estimates, Soul create/wait, model lookup.
- Claude client: `messages.parse` + `zodOutputFormat`, cached `craft.md` system block (1 h), director/QA model split, costs recorded to `claude_runs`.
- Capability registry (`src/providers/capability.ts`): every capability resolves to the first available implementation; API-only fallbacks for inpaint (mask composite), outpaint (pad + refine), upscale (generative or lanczos), reframe (ffmpeg), identity (reference pack). Only `video.cutout` may be unavailable.
- Local providers: ffmpeg (static binary, progress parsing), ffprobe, sharp (thumbs, vision downscale, composites, similarity/hue checks).
- Mock providers (`MOCK_PROVIDERS=1`): real PNG/MP4 fixtures through sharp/ffmpeg, mock shot lists, storyboards, QA and critiques; `MOCK_LATENCY_MS` controls per-output latency.
