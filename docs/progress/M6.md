# M6 — Editing

- Asset drawer edit ops: refine (instruction), relight (lighting editor), inpaint (mask brush → mask upload → native or composite), outpaint (aspect + scene hint), clean plate, upscale, crop, adjust (brightness/saturation/contrast/warmth), and for video: reframe, extend, object swap, upscale.
- Every edit is a job with lineage (parent asset, version) visible under Versions; results re-enter review as new candidates when they derive from a candidate.
