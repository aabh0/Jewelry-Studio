# Jewelry Studio

Local, single-user studio app for producing jewelry campaign visuals (stills and short videos) on top of the Higgsfield Cloud API, the Higgsfield CLI, and the Anthropic Claude API.

Status: planning complete. See `PLAN.md` (the approved build spec) and `docs/research/` (reference material). Implementation starts at milestone M0 in PLAN.md §22.

Quick orientation:
- `PLAN.md` §0 — what the owner must provide, hard rules, build order
- `PLAN.md` §8.4 — capability registry (dual-lane Higgsfield design with API-only fallbacks)
- `PLAN.md` §22 — milestones and acceptance criteria
